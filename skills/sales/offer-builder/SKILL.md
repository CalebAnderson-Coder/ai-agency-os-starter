# Offer Builder

Turn "I do AI automation" into a productized offer a buyer can say yes to in one read.

## Value equation (score each 1-10)
Value = (Dream outcome x Perceived likelihood) / (Time delay x Effort & sacrifice).
Raise the top, shrink the bottom. Every component of the offer must move one of these four levers.

## Steps
1. **Dream outcome** in the buyer's words, with a number and a timeframe ("+20 booked jobs/month in 60 days").
2. **List every problem** that blocks it (aim for 15+). Each problem becomes a deliverable.
3. **Productize**: name the offer, fixed scope, fixed price, fixed timeline. Name pattern: *[Outcome] + [Mechanism] + [Timeframe]* (e.g. "The 14-Day Missed-Call Recovery System").
4. **Stack**: core deliverable + 3-5 bonuses that kill specific objections (setup done-for-you, templates, training video, 30-day support).
5. **Risk reversal**: conditional guarantee tied to an action the client controls ("If you don't get X after doing Y, we work free until you do").
6. **Scarcity/urgency that is true**: onboarding slots per month, price increase date.
7. **Pricing ladder**: free audit -> $500-1.5k setup offer -> $1-3k/mo retainer. Front-end offer must be easy to say yes to.

## Output
A one-page offer doc: name, promise, who it's for / not for, deliverables, bonuses, guarantee, price, timeline, 3 headline options, and the 5 objections + answers.
