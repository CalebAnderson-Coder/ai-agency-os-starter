# Privacy Policy: AI Agency OS Starter

Last updated: October 23, 2026

AI Agency OS Starter is a set of Claude Code skills (instruction files). It has no server, no MCP servers, no analytics and no network calls of its own.

**What it handles.** The client-workspace skills read and write plain files inside your own project folder. Those files can include your clients' names, contact details, scope documents and notes that you choose to add.

**Where it is stored.** Only on your machine (or wherever your project folder lives). Nothing is sent to the plugin author or any third-party service by the plugin.

**Retention.** The author receives and retains no data. You can delete the workspace files at any time.

**Claude.** Content you work on is processed by Claude under your own Anthropic account terms, as with any Claude Code session.

**Contact.** Open an issue at https://github.com/CalebAnderson-Coder/ai-agency-os-starter/issues
