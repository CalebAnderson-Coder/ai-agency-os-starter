# Examples
`acme-plumbing/` is a fictional client used to show `scope-guard` end to end.

```bash
mkdir -p ~/agency/clients && cp -R examples/acme-plumbing ~/agency/clients/
cd ~/agency/clients/acme-plumbing && claude
```
Then paste the email from `request.md` and say: *"Run scope-guard on this request."* Compare with `expected-output.md`.
